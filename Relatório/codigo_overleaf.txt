\subsection{Mapeamento de Códigos}

O compilador utiliza uma organização de código estrutural, contendo a main que rege o funcionamento principal e algumas funções derivadas. as funções e utilitários são:

\begin{enumerate}
    \item \textbf{main} - função principal, desenvolve a lógica de leitura e escrita do código chamando as demais funções.
    \item \textbf{identar} - retira comentarios e espaços iniciais do código
    \item \textbf{pegar_palavra} - obtem a proxima palavra da posição para analizarmos.
    \item \textbf{obeter_opcode} - obtem o opcode a partir do mnemonico fornecido.
    \item \textbf{obter_dado} - verifica se o operando é um binario, hexadecimal ou decimal e chama alguma das funções a baixo.
    \item \textbf{trad_hexa} - traduz o operando se for hexadecimal para binário.
    \item \textbf{trad_bin} - identa o operando caso ele já seja binario.
    \item \textbf{trad_dec} - traduz o operando se for decimal para binário.
    \item \textbf{erro} - acionada em caso de erro, interrompe o processo;
\end{enumerate}


\subsection{Estrutura do assembly}

o assembly criado no nosso projeto segue a logica de:
\begin{itemize}
    \item Cada instrução utiliza 1 minemonido e de 0 a 2 operandos.
    \item Cada instrução ocupa uma linha, com uma instrução por linha.
    \item A sequencia deve seguir, primeiro o mnemônico e depois os operandos, na mesma linha e em seguida.
    \item Os mnemonicos devem estar em letra maiúscula. 
    \item comentarios são feitos com "//".
    \item os parametros podem ser em hexadecimal, decimal ou binario. Para tanto, utilize os prefixos "0x", "0d", "0b" respectivamente.
    \item os parametros não podem passar do valor 248, valor maximo permitido.
\end{itemize}

\subsection{Funcionamento do Compilador}

Tendo um arquivo "assembly.txt", com os dados seguindo a estrutura acima. O compilador abrira esse arquivo para a leitura e criará um outro arquivo "dados.bin".

Para cada linha, o compilador fará os seguintes passos:

\begin{itemize}
    \item Identa a linha, retirando os comentarios e os espaços iniciais;
    \item Caso não sobre nada na linha, significa que a linha não contem uma instrução, então pula para a próxima.
    \item Caso ache uma intrução, ele obtem o minemonico correspondente.
    \item Com o mnemonico, traduzimos para o opcode correspondente, escrevemos e pegamos a quantidade de parametros.
    \item Para a quantidade de parametros, o compilador lê os operandos e traduz para binário, escrevendo no arquivo.
    \item caso ocorra algum erro, o compilador aciona a função de erro.
\end{itemize}



\subsection{Mensagens de Erro}

Quando uma ocasião de erro é acionada, o compilador exclui o arquivo binário e imprime a mensagem de erro.

Todos os casos seguem a estrutura:

\begin{itemize}
    \item \textbf{ERROR -- line: <numero da linha>: <mensagem de erro> <palavra errada>} 
    \item \textbf{Excluindo arquivo}
\end{itemize}

Temos no total 5 possibilidades de mensagens de erro, comportando cada casos:

\begin{enumerate}
    \item \textbf{"arquivo nao aberto"} - acionada caso não ache o arquivo assembly.txt.
    \item \textbf{"comand not found"} - acionado quando o mnemónico não é achado na tabela de mnemonicos.
    \item \textbf{"missing arguments"} - acionado quando temos menos parametros que o requisitado para a instrução;
    \item  \textbf{"argument invalid:"} - acionado quando o parametro da instrução não está certo. seja por erro de digitação ou por que o dado utrapassou 8 bits.
    \item \textbf{"most arguments"} - acionado quando temos mais parametros que os necessários para mnemónico.
\end{enumerate}

\section{Requisitos do Processador}
\begin{itemize}
    \item Palavra de pelo menos 8 bits.
    \item Registradores obrigatórios: 3 para operações matemáticas e 1 para flags.
    \item Conjunto mínimo de instruções:
        \begin{itemize}
            \item Movimentação e transferência de dados
            \item Manipulação de bits e deslocamento
            \item Operações aritméticas: ADD, SUB, MUL, DIV, MOD
            \item Operações relacionais: comparação
            \item Operações lógicas: AND, OR, NOT, XOR
            \item Outros: macros, constantes, operações I/O, NOP, HALT
        \end{itemize}
\end{itemize}
